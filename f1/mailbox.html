📬 The mailbox

One five-minute job, once, by one person. After this every phone in the league sees the same picks, the same standings and the same deadline.

Why it is needed. Without a mailbox the app still works, but each phone keeps its own private copy and nobody sees anybody else's picks — which would be worse than the group text. The mailbox is a free Google script that holds the league. It is yours, it costs nothing, and nobody needs an account to use it.

You will need to be signed in to Google. Do this on a computer if you have one handy — it works on a phone or tablet, it is just more comfortable with a keyboard.

  1. Open a new Google script

    This is where the mailbox will live.

    Open script.google.com ↗

    Tap New project, then select the few lines of sample code it starts with and delete them, so the page is empty.

  2. Copy the script, paste it in

    One tap copies the whole thing. Then paste it into that empty page.

    Then in the Google page: paste, tap 💾 save, and name the project Pit Wall mailbox.

    Couldn't copy it for you — select all of this and copy it by hand:

    Or open the file itself and copy from there.

  3. Publish it

    Top right: Deploy → New deployment. Tap the ⚙ gear and choose Web app. Then set:

    • Execute as: Me
    • Who has access: Anyone

    Tap Deploy, then Authorize access. Google shows a scary warning because the script is yours and not from a shop — choose Advanced, then Go to Pit Wall mailbox (unsafe). It is your own script; that is the normal path.

  4. Copy the web app address

    Google now shows a Web app URL. It is long and ends in /exec. Copy it, then come back here.

  5. Paste it here

    This connects your phone and makes the link you text everyone else.

    That's it — the mailbox is yours.

    Two things left, in this order:

    1 · Connect this phone →

    That opens Pit Wall and joins it to the mailbox. Your league data seeds it, so nothing is lost.

    Paste that one in the group text. Whoever taps it is on the league — no pasting, no settings. Then they pick their name and a four digit PIN.

    Treat that link like a house key. Anyone who opens it is in the league. The group text is the right place for it; a public post is not.

You can do all of this from inside the app instead — Setup → Mailbox has the same steps. If something goes wrong, nothing is broken: the app keeps working on each phone on its own until the mailbox answers.
