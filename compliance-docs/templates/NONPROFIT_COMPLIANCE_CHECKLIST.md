# Nonprofit Compliance Checklist

A comprehensive checklist for ongoing nonprofit compliance requirements. Review quarterly and before key deadlines.

## Annual IRS 990 Filing (Due 5½ months after fiscal year-end)

### Pre-Filing Preparation
- [ ] Gather all financial records for the year (Jan-Dec or your fiscal year)
- [ ] Complete detailed income statement (all revenue sources)
- [ ] Compile list of all expenses by category
- [ ] Reconcile bank statements
- [ ] Document in-kind donations and their fair market value
- [ ] Prepare list of Board members and officers with titles
- [ ] Collect compensation records for key employees

### Form 990-N (e-postcard) - If gross receipts < $50,000
- [ ] Confirm organization qualifies (revenue threshold)
- [ ] Gather EIN and principal officer information
- [ ] Access IRS e-file system
- [ ] Complete Form 990-N with accurate organization info
- [ ] Submit electronically before deadline
- [ ] Print confirmation receipt and file with records

### Form 990-EZ - If gross receipts $50,000–$200,000
- [ ] Complete Part I: Summary information
- [ ] Complete Part II: Revenue section with all income sources
- [ ] Complete Part III: Expenses by functional category
- [ ] Complete Part IV: List of officers, directors, key employees
- [ ] Sign and date by authorized officer
- [ ] Have CPA review (recommended)
- [ ] File electronically or by mail with IRS
- [ ] Retain copy in compliance-docs/990-filings/

### Form 990 - If gross receipts > $200,000
- [ ] Engage qualified CPA or tax professional
- [ ] Complete all required schedules:
  - [ ] Schedule A (Public Charity Status)
  - [ ] Schedule B (List of Contributors) - **CONFIDENTIAL**
  - [ ] Schedule C (Political Campaign Activity)
  - [ ] Schedule D (Supplemental Financial Statements)
  - [ ] Schedule O (Supplemental Information)
  - [ ] Other schedules as applicable to your organization
- [ ] Obtain Board approval of 990 filing
- [ ] File with IRS by deadline
- [ ] Store Schedule B separately with restricted access

### Post-Filing
- [ ] File annual Form 990-N/EZ/990 with IRS
- [ ] Obtain IRS filing receipt/confirmation
- [ ] File 990 with state (if required)
- [ ] Make 990 publicly available (if applicable - Form 990-N organizations may be exempt)
- [ ] Archive filed return in compliance-docs/archive/

## State Compliance

### Secretary of State Annual Report
- [ ] Check due date for your state (varies by state)
- [ ] Confirm incorporation status is active
- [ ] Update principal officer/agent for service of process if changed
- [ ] File annual report with filing fee
- [ ] Retain copy of filed report

### State Charitable Registration (if required)
- [ ] Verify registration status with state attorney general
- [ ] Renew annual charitable solicitation registration
- [ ] File Form 199N or state equivalent (varies)
- [ ] Update contact information if moved
- [ ] Pay any required renewal fees

### State Tax Exemption Certificate
- [ ] Verify state tax-exempt status is current
- [ ] Renew as required by state (typically every 2 years)
- [ ] Obtain updated exemption certificate
- [ ] File with all vendors requiring proof of exempt status

## Financial & Banking Compliance

### Bank Account Maintenance
- [ ] Verify account is registered to organization (not individual)
- [ ] Maintain appropriate account documentation on file
- [ ] Complete annual customer information refresh with bank
- [ ] Address any dormant account notices immediately
- [ ] Update signatory list if officers change
- [ ] Obtain statement of account holders and signatories

### Record Keeping
- [ ] Retain all bank statements for current + 7 prior years
- [ ] File bank reconciliations monthly
- [ ] Document all large transactions with supporting receipts
- [ ] Keep general ledger organized by functional category
- [ ] Maintain audit trail for all financial transactions
- [ ] Back up all digital financial records

### Accounting Standards
- [ ] Use consistent accounting method (accrual or cash basis)
- [ ] Document depreciation policy for fixed assets
- [ ] Properly record in-kind donations at fair market value
- [ ] Separate restricted vs. unrestricted funds
- [ ] Review and document all fund transfers
- [ ] Conduct annual financial review or audit if revenue > $500K

---

## Donor Compliance & Documentation

### Donor Records
- [ ] Maintain separate file for each donor
- [ ] Record donation amount, date, and any restrictions
- [ ] Note donor contact information and preferences
- [ ] Document in-kind donations with FMV assessment
- [ ] Keep Schedule B (donor list) secure and restricted
- [ ] Update donor information annually

### Charitable Contribution Letters
- [ ] Issue written acknowledgment for gifts > $250
- [ ] Include organization name, EIN, and exemption status
- [ ] State amount of deductible contribution
- [ ] Describe goods/services received in exchange (if any)
- [ ] Include statement about estimated value of goods/services
- [ ] Do not include pledge letters as charitable gifts

### Donation Tracking
- [ ] Log all donations in donor management system
- [ ] Flag restricted donations with specific restrictions
- [ ] Track pledge vs. received donations separately
- [ ] Monitor donor payment schedules
- [ ] Maintain fundraising records
- [ ] Document any fundraising costs/expenses

---

## Board Governance

### Board Meetings
- [ ] Hold minimum required meetings (typically 4/year)
- [ ] Document all meeting minutes
- [ ] Maintain attendance records
- [ ] Record all board decisions and votes
- [ ] Approve financials at board meeting
- [ ] Approve major expenditures and policy changes

### Board Documentation
- [ ] Maintain current Board bylaws
- [ ] Document Board member terms and conflicts of interest
- [ ] Keep Board member list with titles and addresses
- [ ] Update Board roster annually
- [ ] Obtain Board member acknowledgments/certifications
- [ ] Maintain conflict of interest policy

### Officer Responsibilities
- [ ] Executive Director or President: Operational oversight
- [ ] Treasurer: Financial management and 990 accuracy
- [ ] Secretary: Record keeping and compliance documentation
- [ ] Assign compliance officer (may be Treasurer or Executive Director)
- [ ] Document officer transitions and succession plans

## Tax Compliance

### Tax-Exempt Status
- [ ] Confirm 501(c)(3) determination letter is on file
- [ ] Display IRS determination letter or notice
- [ ] Verify EIN matches all filings
- [ ] Monitor IRS correspondence for status changes
- [ ] Respond promptly to any IRS inquiries
- [ ] Keep copies of all IRS communications

### Payroll & Employment
- [ ] File quarterly payroll tax returns (Form 941)
- [ ] Pay employment taxes timely
- [ ] Issue W-2s to all employees by Jan 31
- [ ] Issue 1099s to contractors as required (if paid > $600)
- [ ] Maintain payroll records for 7 years
- [ ] Comply with IRS backup withholding requirements

### Income Tax Reporting
- [ ] File Form 990 (all levels) by deadline
- [ ] Report unrelated business income on Form 990-T (if applicable)
- [ ] File state income tax returns as required
- [ ] Keep tax return copies and supporting schedules
- [ ] Document tax exemption for all applicable taxes

## Insurance & Risk Management

### Required Insurance
- [ ] Maintain general liability insurance ($1M+ recommended)
- [ ] Officers & Directors liability insurance (if applicable)
- [ ] Cyber liability/data protection insurance (if collecting donor data)
- [ ] Property insurance for organization assets
- [ ] Vehicle insurance for vehicles used by organization
- [ ] Workers' compensation (required if you have employees)

### Insurance Documentation
- [ ] Keep current insurance policies and certificates
- [ ] Verify coverage limits are adequate
- [ ] Maintain proof of insurance payments
- [ ] Review coverage annually
- [ ] Update certificates of insurance when renewed

---

## Document Management & Record Retention

### Required Records (Keep 7 years minimum)
- [ ] All IRS Forms 990 and supporting schedules
- [ ] Bank statements and reconciliations
- [ ] General ledger and financial journals
- [ ] Donor records and contribution receipts
- [ ] Board meeting minutes and resolutions
- [ ] Employee payroll records and tax forms
- [ ] Contracts and agreements
- [ ] Grant reports and grant agreements

### Document Security
- [ ] Store Schedule B and confidential records separately
- [ ] Limit access to sensitive financial documents
- [ ] Maintain physical security for records
- [ ] Back up digital records regularly (offsite backup)
- [ ] Use password protection for sensitive digital files
- [ ] Document who has access to confidential materials

### Annual Archive
- [ ] Move completed year records to archive folder
- [ ] Label with tax year and organization name
- [ ] Create index of archived materials
- [ ] Store in secure location
- [ ] Verify backup copies exist

## Notes & Reminders

**Important Deadlines:**
- 990-N/EZ/990 Due: 5½ months after fiscal year-end
- Payroll taxes: Quarterly by IRS deadlines
- W-2/1099 distribution: January 31
- State annual reports: Varies by state (see Secretary of State)
- Sales tax exemption certificate renewal: Typically 2 years

**Risk Areas:**
- Missing IRS filing deadline → automatic loss of 501(c)(3) status
- Inaccurate 990 reporting → penalties and potential revocation
- Inadequate donor documentation → IRS audit risk
- Missing payroll tax filing → penalties and interest
- Poor record retention → inability to respond to IRS inquiries

**Key Contacts to Maintain:**
- [ ] CPA or tax professional phone/email
- [ ] Legal counsel phone/email
- [ ] IRS Employee Identification Section: 1-800-829-4933
- [ ] State Attorney General Charitable Division
- [ ] State Secretary of State Office
- [ ] Bank account manager contact
